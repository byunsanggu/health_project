# 촬영 목록

엔진에 직접 물어서 만든 순서입니다. 추측이 아닙니다.

설정 조합 720판을 전부 돌려 **종목별 처방 횟수**를 셌습니다. 다만 빈도만으로 줄을
세우면 컨센트레이션 컬이 백 스쿼트보다 위로 옵니다 — 덤벨만 있으면 되니 모든 헬스장
조합에서 나오기 때문입니다. 영상이 급한 건 *자주 나오는 것*이 아니라 **모르면 다치는**
것이라, **관절 부하 0.7 이상**을 먼저 놓고 그 안에서 빈도순으로 정렬했습니다.

## 몇 개까지 찍으면 되나

| 상위 | 덮는 비율 | 걸리는 시간(대략) |
| --- | --- | --- |
| 17개 (1단계 전부) | 19% | 1.7시간 |
| 30개 | 59% | 3시간 |
| 50개 | 88% | 5시간 |
| 83개 | 100% | 8.3시간 |

**1단계 17개를 먼저 찍고 앱에 넣어 보세요.** 83개를 다 찍고 나서야 "화면에서
작아서 안 보이네"를 알게 되면 전부 다시 찍어야 합니다. 나머지는 동작 애니메이션이
그대로 나오므로 빈 칸으로 보이지 않습니다.
