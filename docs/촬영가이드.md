# 촬영 가이드

직접 찍는 게 사는 것보다 낫습니다. 이유가 넷입니다.

1. **저작권이 이쪽에 있습니다.** 라이선스 만료도, 재계약도, 사용 범위 제한도 없습니다.
   투자 실사나 인수 과정에서 에셋 권리는 반드시 확인받는 항목인데, 여기서 걸릴 게 없습니다.
2. **한국 헬스장, 한국 기구, 한국 큐입니다.** 해외 스톡은 우리 사용자가 쓰지 않는 기구가 섞여 있습니다.
3. **20년 경력이 화면에 나옵니다.** 이건 에셋이 아니라 마케팅 자산입니다. 스톡 렌더로는 못 만듭니다.
4. **돈이 거의 안 듭니다.** 폰과 삼각대면 끝입니다.

---

## 장비

| | 쓰는 것 | 사지 않아도 되는 것 |
| --- | --- | --- |
| 카메라 | 쓰시는 폰 | 미러리스·DSLR |
| 고정 | 삼각대 + 폰 거치대 (2~3만 원) | 짐벌 |
| 조명 | 헬스장 조명 그대로 | 조명 장비 |
| 소리 | **안 씁니다** | 마이크 |

소리를 안 쓰는 이유: 화면의 큐는 글로 나갑니다. 무음이면 헬스장에서 이어폰 없이 볼 수 있고,
소리가 없으니 배경 음악 저작권 문제가 원천적으로 없습니다. **음악은 절대 넣지 마세요** —
깨끗한 영상에 저작권 문제를 만드는 가장 흔한 경로입니다.

## 폰 설정

- **1080p / 60fps.** 4K는 파일만 커집니다. 60fps는 나중에 느리게 돌릴 여지를 남깁니다.
- **가로로 찍습니다.** 앱에서 4:3으로 잘라 씁니다.
- 손전등·플래시 끄기, 화면 잠금 끄기.

## 화면 잡기

- **발끝부터 머리 위 여유까지** 다 들어와야 합니다. 초보자의 실수는 대부분 발에서 나옵니다 —
  뒤꿈치가 뜨는지, 발끝 방향이 맞는지. **발을 자르면 영상의 절반이 날아갑니다.**
- 카메라 높이는 **명치 정도**. 바닥에 두고 올려 찍으면 상체 각도가 실제보다 서 보입니다.
- 창문이나 밝은 조명을 **등지지 마세요.** 실루엣만 나옵니다. 빛을 앞에 두세요.
- 옷은 **몸에 붙고 배경과 대비되는 색.** 어두운 헬스장에서 검은 옷은 윤곽이 안 보입니다.
- 배경에 **다른 회원이 나오지 않게.** 법적으로도, 보기에도 그렇습니다.

## 각도

종목마다 봐야 하는 게 다릅니다. **`docs/촬영목록.md`에 종목별로 적어 뒀습니다.**

대략의 기준:

| 패턴 | 각도 | 왜 |
| --- | --- | --- |
| 힌지 · 스쿼트 · 런지 | 측면 | 허리와 무릎 각도. 이 패턴은 이게 전부입니다 |
| 수평 푸시 · 수평 풀 | 측면 | 바가 닿는 위치, 몸통이 같이 젖혀지는지 |
| 수직 푸시 | 측면 + 정면 | 측면은 바 궤적, 정면은 팔꿈치 벌어짐 |
| 수직 풀 | 정면 | 그립 너비와 어깨 말림. 측면으론 안 보입니다 |
| 고립 | 정면 | 반동. 고립 종목은 반동이 거의 전부입니다 |

## 찍는 법

**종목당 두 컷을 찍습니다.**

1. **정상 컷** — 천천히, 정확하게 **3회**. 한 세트를 다 하지 마세요. 3회면 충분하고 편집이 쉽습니다.
2. **실수 컷** — 흔한 실수를 **일부러** 합니다. 무게를 가볍게 하고 하세요.

실수 컷이 사실 더 중요합니다. 초보자는 "이렇게 하세요"보다 **"이러면 안 됩니다"**를 훨씬 잘
기억합니다. 어떤 실수를 보여줄지는 종목마다 `docs/촬영목록.md`에 이미 적혀 있습니다 —
앱에 들어 있는 실수 목록과 같은 것이라, 글과 영상이 어긋나지 않습니다.

**시작 자세와 끝 자세를 똑같이** 하세요. 영상이 반복 재생되는데, 다르면 이어질 때 튑니다.

## 편집 · 내보내기

폰 기본 편집 앱으로 **앞뒤만 자르면 됩니다.** 4~8초, 3회 반복.

압축은 컴퓨터에서 한 번에 합니다. 폴더에 파일을 다 모아 두고:

```
for f in *.mov *.mp4; do
  ffmpeg -i "$f" -vf "scale=-2:720" -r 30 -c:v libx264 -crf 28 \
         -preset slow -movflags +faststart -an "out/${f%.*}.mp4"
done
```

- `scale=-2:720` — 폰 화면에 720p면 충분합니다
- `-an` — **소리를 뺍니다.** 용량도 줄고 저작권 여지도 없앱니다
- `-crf 28` — 한 개 300~800KB로 떨어집니다
- `+faststart` — 다 받기 전에 재생이 시작됩니다. 헬스장 와이파이에서 체감이 큽니다

## 파일 이름과 등록

```
prototype/demo/back-squat.mp4            정상
prototype/demo/back-squat--mistake.mp4   실수
```

종목 id는 `docs/촬영목록.md`에 종목마다 적혀 있습니다.

파일을 넣은 뒤 `prototype/demoClips.js`의 목록에 한 줄 추가합니다.

```js
var CLIPS = [
  { id: 'back-squat', mistake: true },
  { id: 'barbell-bench-press', mistake: false },
];
```

**적은 것만 영상으로 바뀝니다.** 안 적은 종목은 지금의 동작 애니메이션이 그대로 나오므로
빈 칸이 생기지 않습니다. 83개를 다 찍을 때까지 기다릴 필요가 없습니다.

## 순서

`docs/촬영목록.md`가 순서를 정해 줍니다. 엔진 설정 720판을 돌려 처방 빈도를 세고,
관절 부하가 높은 것을 앞으로 뺀 목록입니다.

**1단계 17개**가 첫 촬영 분량입니다. 그중 13개가 랙에서 찍히므로 삼각대를 거의 안 옮깁니다.
1시간 반이면 됩니다.

찍고 나서 **앱에 한 번 넣어 보고** 나머지를 찍으세요. 83개를 다 찍은 뒤에
"화면에서 작아서 안 보이네"를 알게 되면 전부 다시 찍어야 합니다.

## 법적으로 챙길 것

- **헬스장 촬영 허가.** 사장님께 받으시고, 문자로라도 남겨 두세요. 말로만 받으면 나중에 곤란합니다.
- **다른 회원이 화면에 나오면 안 됩니다.** 알아볼 수 있으면 초상권 문제입니다. 한가한 시간에
  찍는 게 제일 확실합니다.
- **본인이 모델이면 별도 동의서가 필요 없습니다.** 다른 분이 모델이면 **서면 동의**를 받으세요.
  용도(앱 게시), 기간, 범위를 적어야 합니다.
- **기구 브랜드 로고.** 배경에 우연히 들어가는 건 대체로 문제가 없지만, 로고가 주인공이 되거나
  그 브랜드가 후원하는 것처럼 보이면 안 됩니다. 각도를 살짝 틀면 됩니다.
- **음악 금지.** 위에 썼지만 한 번 더 씁니다.

이 문서는 법률 자문이 아닙니다. 출시 전에 변호사 검토를 받으세요 — 특히 모델 동의서 양식은
직접 만들지 마시고 검토받으시는 게 낫습니다.
