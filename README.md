# 적응형 볼륨 주기화 트레이닝 엔진

주간 볼륨과 피로도를 읽고 **다음 주 훈련량을 스스로 조절하는** 트레이닝 엔진입니다.

대부분의 운동 앱은 "오늘 뭐 할지"를 정해줍니다. 이 엔진은 그다음 질문을 풉니다 —
**이번 주 볼륨이 회복 가능한 범위인가, 지금 몸이 이 루틴을 받아낼 상태인가.**

## 왜 이걸 만드나

현장에서 회원이 정체되는 지점은 종목 선택이 아니라 총량 관리입니다.

| 기존 앱이 하는 것 | 이 엔진이 추가로 하는 것 |
|---|---|
| 오늘의 루틴 추천 | 부위별 **주간 유효 세트** 집계와 MEV/MAV/MRV 구간 판정 |
| kg × reps 기록 | **RIR(남은 반복 수)** 기반 수행 품질 측정 |
| 세션 단위 진행 | 4~6주 **메조사이클**과 자동 **디로드** 삽입 |
| 주간 총량만 계산 | **훈련 빈도** — 같은 볼륨도 한 세션에 몰면 덜 인정한다 |
| 고정 루틴 | **통증 체크인**에 따른 종목 자동 대체 |
| 고정 증량 단위 | **등록한 헬스장 기구**가 만들 수 있는 중량으로만 처방 |
| "알아서 넣으세요" | 첫 종목의 **시작 중량 추정**과 탐색 세트 보정 |
| 자가 신고 경력 | **경력 4단계**를 훈련 기간·기록과 대조해 과대 신고를 낮춰 잡음 |
| 고정 루틴 목록 | 경력·일수·보유 기구로 **첫 프로그램 자동 생성** |
| RIR 신고를 그대로 신뢰 | **실패 세트와 대조해 신고 편향을 역산**하고 집계·처방에 반영 |
| 온라인 전제 | **오프라인 우선** 저장 — 헬스장 지하에서도 기록이 남는다 |

## 빠르게 확인하기

```bash
npm install     # typescript, @types/node (런타임 의존성은 없습니다)
npm test        # 249개 테스트
npm run check   # 타입체크 + 테스트

node src/demo.ts   # 6주 블록 시뮬레이션
```

`demo.ts`는 가상의 중급자(78kg·중급)를 주 4회 6주간 훈련시키며 엔진이 한 바퀴 도는 것을 보여줍니다.
3주차에 어깨 통증이 생기면 종목이 대체되고, 4주차에 피로 신호가 임계를 넘으면 디로드가 삽입되고,
5주차에 새 축적 블록이 시작됩니다.

```
3주차 · 축적 3주차 · 목표 RIR 2 · 피로 점수 3
  ⚠ 평균 RIR이 3.0 → 2.0로 떨어졌습니다. 같은 중량이 더 무겁게 느껴지는 상태입니다 (+2)
  ⚠ 어깨 통증 4점. 바벨 벤치프레스 대신 머신 체스트프레스를 권합니다.

4주차 · 디로드 · 목표 RIR 4 · 피로 점수 9
  ⚠ 13개 종목의 추정 1RM이 지난주보다 떨어졌습니다 (랫 풀다운, 바벨 컬, 백 스쿼트 외) (+3)
  ⚠ 최근 7일 중 4일에 3점 이상 관절 통증이 보고됐습니다 (+3)

5주차 · 축적 1주차 · 목표 RIR 3 · 피로 점수 3
```

한 바퀴:

```
세트 기록(RIR 포함)

   → frequencyReport   분배가 맞는지
```

## 핵심 규칙

### 유효 세트 (`volume.ts`)

kg × reps만 세면 볼륨 관리가 무의미해집니다. 20회 남기고 끝낸 세트와 실패 직전까지 간 세트는 같은 1세트가 아닙니다.

| 조건 | 가중치 |
|---|---|
| 워밍업 | 0 |
| RIR 0~3 | 1.0 |
| RIR 4 | 0.7 |
| RIR 5+ | 0.3 |
| 5회 미만 | × 0.8 (근력 자극이 주) |
| 30회 초과 | × 0.6 |

여기에 종목별 부위 기여도(주동근 1.0, 협응근 0.5)를 곱해 합산합니다.
벤치프레스 4세트 = 가슴 4세트 + 삼두 2세트 + 전면삼각근 2세트.

### 훈련 빈도 (`frequency.ts`)

세션 경계를 무시하고 전부 더하면 안 됩니다. **한 세션에서 한 부위가 온전히 인정받는 상한은 9세트**이고, 넘은 만큼은 절반만 셉니다.

```
가슴 16세트를 하루에  → 유효 11.5세트 (4.5세트가 버려짐)
가슴 16세트를 이틀에  → 유효 16세트
```

권장 빈도는 볼륨에서 역산합니다 — 4세트 미만은 주 1회, 그 위는 최소 주 2회, 세션당 상한을 넘기면 `ceil(볼륨 ÷ 9)`회.

**볼륨보다 분배가 먼저입니다.** 한 세션에 몰린 부위에는 세트를 더 넣지 않고 "주 N회로 나누세요"를 먼저 처방합니다. 버려지는 세트를 늘리는 건 피로만 늘리니까요. 단 MEV 미만이면 늘리는 게 먼저고, MRV 초과면 줄이는 게 먼저입니다.

### 볼륨 진행 (`mesocycle.ts`)

| 현재 구간 | 처방 |
|---|---|
| MEV 미만 | MEV까지 끌어올림 |
| MEV ~ MAV | 주 +2세트 (피로 신호 있으면 +1) |
| MAV ~ MRV | 주 +1세트 (피로 신호 있으면 유지) |
| MRV 초과 | MRV로 되돌림 |
| 통증 보고 부위 | 유지 |
| 최근 4주 기록 없음 | 처방하지 않고 `neglected`로 따로 알림 |

### 중량 진행 (`load.ts`)

이중 진행 + RIR 보정. **순서가 중요합니다** — 반복 상단에 닿았어도 RIR이 목표보다 모자라면 올리지 않습니다.

| 마지막 본세트 | 처방 |
|---|---|
| 반복 상단 도달 + RIR 여유 | 증량 (여유 2 이상이면 두 칸) |
| 반복 상단 도달 + RIR 부족 | 유지 — RIR부터 확보 |
| 반복 미달 + RIR 여유 2 이상 | 증량 |
| 목표 하단 미달 | 10% 감량 |
| 범위 안 | 유지, 반복 +1 |

### 디로드 판정 (`readiness.ts`)

단일 신호로 결정하지 않습니다. 합산 점수 5점 이상에서 디로드를 권합니다.

| 신호 | 가중치 |
|---|---|
| 주요 종목 추정 1RM 하락 (2종목 이상) | 3 |
| 관절 통증 3점 이상이 주 2일 이상 | 3 |
| MRV 초과 부위 | 1~2 (3부위 이상이면 단독 트리거) |
| 평균 RIR 1 이상 하락 | 2 |
| 평균 수면 6시간 미만 또는 근육통 7점 이상 | 2 |
| 계획된 축적 주차 완료 | 2 |
| 의욕 3점 이하 | 1 |

디로드 주는 **볼륨 절반, 중량 90%, 목표 RIR 4**. 피로의 주된 원인은 볼륨이고, 강도를 유지해야 복귀 시 수행력이 살아 있습니다.

디로드 다음 주는 무조건 훈련으로 복귀하고, 디로드 주의 낮은 기록은 수행력 하락으로 세지 않습니다.
(이 두 규칙이 없으면 디로드가 디로드를 부르는 무한 루프에 빠집니다 — 시뮬레이션으로 잡은 버그입니다.)

### 헬스장 기구 (`gym.ts`)

종목마다 고정된 증량 단위를 쓰는 건 틀렸습니다. **그 헬스장의 기구가 가능한 중량을 결정합니다.**

| 기구 | 무엇이 다른가 |
|---|---|
| 바벨 | 빈 바가 20kg가 아닐 수 있음 (여성용 15, EZ바 10, 스미스머신은 제각각) |
| 플레이트 | 1.25kg 한 쌍이 없으면 2.5kg 단위로 못 올림 |
| 스택 머신 | 5kg 간격이 흔하지만 기구마다 다르고, 보조추가 있기도 함 |
| 플레이트식 머신 | 빈 캐리지가 이미 20~30kg |
| 덤벨 | 보유한 것만 쓸 수 있음 (23kg 덤벨은 없음) |

```
처방 82.5kg → 벤치프레스   82.5kg  (20kg 바 + 한쪽 25 · 5 · 1.25)
처방   37kg → EZ바 컬      37.5kg  (10kg 바 + 한쪽 10 · 2.5 · 1.25)
처방  160kg → 레그프레스    160kg   (20kg 캐리지 + 한쪽 25 · 25 · 20)  한 칸 = 10kg
처방   23kg → 덤벨          22kg   (보유 덤벨)
```

증량 중이면 위로, 감량·통증·디로드 중이면 아래로 붙여 **반올림이 처방의 의도를 되돌리지 않게** 합니다.

기구 보유 여부도 여기서 관리합니다. 종목 단위(`'hack-squat': 'unavailable'`)나 기구 종류 단위(`missingEquipment: ['smith']`)로 끄면, 세션 생성 시 자동으로 대체 종목이 들어가고 대체 후보에서도 빠집니다.

### 시작 중량 (`strength.ts`)

"내가 몇 kg을 들 수 있는지 모른다"에 대한 3단계 답입니다.

| 순서 | 방법 | 신뢰도 |
|---|---|---|
| 1 | **탐색 세트** — 가벼운 무게로 한 세트, RIR만 입력 → 추정 1RM 역산 | 높음 |
| 2 | **종목 간 환산** — 이미 하는 종목의 추정 1RM에서 계수로 변환 | 중간 |
| 3 | **체중 × 경력 기준선** — 5개 앵커 종목의 체중 배수 | 낮음 |

이미 하는 종목이 있으면 2번, 없으면 3번으로 제안하고, **어느 경로든 `needsCalibration`을 붙여** 첫 세트에서 확인하게 합니다. 제안값에는 안전 마진 10%를 빼고 기구 눈금에서 아래쪽으로 붙입니다 — 가벼우면 세트 중에 올리면 되지만 무거우면 다치니까요.

```
체중 75kg · 초급 남성, 기록 없음   → 벤치프레스 32.5kg 제안
벤치 80kg × 8회 (RIR 2) 기록 있음  → 인클라인 덤벨프레스 20kg (한쪽) 제안
탐색 세트 40kg × 10회 (RIR 4)      → 추정 1RM 58.5kg → 작업 중량 40kg 확정
```

환산 계수는 개인차와 기구 편차가 커서 정밀한 값이 아닙니다. "완전히 모름"을 "대충 이 근처"로 옮기는 용도이고, 탐색 세트 한 번이면 실측으로 대체됩니다.

### 경력 단계 (`levels.ts`)

네 단계가 볼륨 랜드마크만 바꾸는 게 아닙니다.

| 단계 | 기준 | 축적 주차 | 1주차 목표 RIR | 세션당 상한 |
|---|---|---|---|---|
| 초보 | 6개월 미만 | 6주 | 4 | 7세트 |
| 중급 | 6개월~2년 | 5주 | 3 | 9세트 |
| 고급 | 2~5년 | 4주 | 2 | 10세트 |
| 전문가 | 5년 이상 | 4주 | 2 | 11세트 |

전문가는 MEV가 가장 높지만 MRV는 그만큼 오르지 않습니다 — 쓸 수 있는 폭이 오히려 좁습니다.

**자가 신고는 그대로 믿지 않습니다.** 현장에서 "중급이요"라고 답하는 사람의 상당수가 6개월 미만입니다. 훈련 개월 수와 (있다면) 기록으로 대조해 **낮은 쪽**을 택합니다. 과대평가된 단계로 볼륨을 처방하면 몇 주 버티다 부상으로 끝나지만, 낮게 잡으면 몇 주 손해로 끝나기 때문입니다.

```
자가 신고 '고급' + 훈련 4개월 → 초보 볼륨으로 시작
자가 신고 '초보' + 훈련 60개월 → 초보 그대로 (올려 잡지 않음)
```

### 기구 카탈로그 (`equipment.ts`)

종목 41개를 하나씩 고르게 하면 아무도 온보딩을 끝내지 못합니다. **기구 단위**로 켜면 종목이 열립니다.

```
바벨 + 랙 + 벤치만            → 9종목
  + 케이블 스테이션            → +6종목 (푸시다운, 페이스 풀, 케이블 플라이 …)
  + 덤벨 세트                → +5종목
기본 구성(19개 기구)          → 73/83종목
```

벤치프레스는 바벨만으로는 안 되고 벤치가 있어야 합니다 — 종목마다 **필요 기구 전부**를 갖춰야 열립니다. 부위별 커버리지도 점검해서 "삼두 종목이 없습니다 → 케이블 스테이션을 추가하세요"까지 알려줍니다.

### 첫 프로그램 생성 (`onboarding.ts`)

설문 하나로 단계 판정 → 분할 선택 → 종목 배치 → 첫 주 처방까지 만듭니다.

| 주당 일수 | 분할 | 부위당 빈도 |
|---|---|---|
| 2일 | 전신 A/B | 2회 |
| 3일 | 전신 A/B/C | 2~3회 |
| 4일 | 상하체 분할 | 2회 |
| 5일 | 혼합 분할 | 2~3회 |
| 6일 | 푸시·풀·레그 2순환 | 2회 |

**주 3일에 PPL을 넣지 않았습니다.** 부위당 주 1회가 되어 빈도 모듈이 말하는 바와 모순되기 때문입니다 — 생성기가 자기 규칙을 어기면 앞뒤가 안 맞습니다.

종목 선택 규칙:
- 메인 자리에는 **프리웨이트 복합 동작**을 우선합니다. 머신으로만 채운 프로그램은 안전해 보이지만 배우는 게 없습니다.
- 초보자는 같은 값이면 관절 부담이 적은 쪽을 고르되, 기본 동작을 밀어낼 만큼은 아닙니다.
- **한 세션에 같은 관절을 거듭 싣지 않습니다.** 이 규칙이 없으면 스쿼트 → RDL → 데드리프트가 한 날에 몰립니다.
- 한 종목은 최대 4세트. 모자란 볼륨은 주간 처방이 몇 주에 걸쳐 올립니다.

### RIR 신뢰도 보정 (`rirCalibration.ts`)

엔진 전체가 사용자가 신고한 RIR 위에 서 있는데, 그 신고가 정확하다는 보장이 없습니다. 초보자는 "3회 남았다"면서 실제로는 실패 직전인 경우가 흔하고, 그대로 믿으면 엔진이 중량을 계속 올려 실패 지점을 넘깁니다.

정답은 알 수 없지만 **기준점은 있습니다 — 실제로 실패까지 간 세트(RIR 0)**입니다.

```
실패 세트: 벤치 80kg × 8회  →  능력치 확정
신고 세트: 벤치 80kg × 8회 "RIR 3"  →  실제로는 RIR 0이었다
                                      → 편향 -3
```

| 판정 | 결과 |
|---|---|
| 과대 신고 | 음수 보정 — **증량을 막아 준다** |
| 정확 | 보정 ≈ 0, 신뢰도 100% |
| 과소 신고 | 양수 보정 — 아직 여유가 있다 |
| 기준 세트 없음 | 보정하지 않고, 가끔 실패까지 가 보라고 안내 |

기준 세트가 3개 미만이면 계산만 하고 **적용하지 않습니다.** 표본이 얕은데 건드리면 더 나빠집니다. 보정이 들어가면 처방 근거에 `RIR 3→1(보정)`처럼 그 사실을 표시합니다 — 사용자 몰래 숫자를 바꾸지 않습니다.

보정값은 유효 세트 집계(`volume.ts`)와 중량 처방(`load.ts`) 양쪽에 적용됩니다.

### 반복 대비 강도 (`repmax.ts`)

Epley 식 `w × (1 + reps/30)`은 선형이라 고반복 구간에서 능력을 과대 추정합니다. 8회 실패한 사람의 1RM은 맞게 나오지만, 거기서 15회 가능한 중량을 역산하면 실제보다 무겁게 나옵니다. RIR 보정처럼 **서로 다른 반복 구간을 비교하는 계산에서는 이 오차가 그대로 편향**이 됩니다.

그래서 현장에서 쓰는 %1RM 표를 씁니다. 정직하게 신고하는 사람에게 +1의 가짜 편향이 나오던 문제가 이걸로 사라졌습니다.

### 주간 스케줄 (`schedule.ts`)

요일 배치와 세션 순서를 따로 풀지 않고 같이 풉니다. 같은 부위를 이틀 연속 때리면 회복이 안 되는데, 그건 요일만 봐서도 세션 내용만 봐서도 알 수 없기 때문입니다.

- 훈련일을 한쪽에 몰지 않고 주에 고르게 폅니다 (주 3회 → 월·수·금)
- 가능한 요일을 지정하면 그 안에서 가장 고르게 펴진 조합을 고릅니다
- 붙어 있는 날에 같은 부위가 겹치지 않도록 세션 순서를 정합니다
- 연속 훈련일이 단계 권장(초보 2일, 그 외 3일)을 넘으면 경고합니다

### 휴식 시간 (`rest.ts`)

볼륨을 관리하면서 휴식을 안 다루면 앞뒤가 안 맞습니다. 90초 쉬고 한 4세트와 3분 쉬고 한 4세트는 같은 4세트가 아닙니다.

| 조건 | 휴식 |
|---|---|
| 고립 운동 | 60~75초 |
| 복합 · 6회 이하 | 180초 |
| 복합 · 7~12회 | 150초 |
| 복합 · 13회 이상 | 120초 |
| 목표 RIR ≤ 1 | +30초 |
| 허리 부담 0.8 이상 | +30초 |

### 오프라인 저장 (`storage.ts`)

헬스장 지하에는 신호가 없습니다. 서버를 기다리지 않고 로컬에 먼저 쓰고, 보낼 것들을 아웃박스에 쌓았다가 연결되면 흘려보냅니다.

- 모든 기록이 `id` · `updatedAt` · `deviceId`를 갖습니다
- 충돌은 **마지막 수정 시각**으로 해결하고, 같으면 기기 id로 순서를 정해 **어느 기기에서 보든 같은 결과**가 나옵니다
- 삭제는 표시만 남깁니다 — 실제로 지우면 다른 기기가 자기 사본으로 되살립니다
- 저장소가 막힌 환경(시크릿 창)에서도 앱이 죽지 않습니다

### 통증 게이트 (`pain.ts`)

세션 생성 시 **통증 판정이 부하 계산보다 먼저** 적용됩니다. 순서를 바꾸면 아픈 관절에 어제보다 무거운 것을 얹게 됩니다.

| 통증 점수 | 관절 스트레스 0.6 이상 | 0.3 ~ 0.6 | 0.3 미만 |
|---|---|---|---|
| 7 ~ 10 | 중단 + 진료 권고 | 중단 + 진료 권고 | 수행 |
| 3 ~ 6 | 대체 운동 | 중량 90% | 수행 |
| 1 ~ 2 | 중량 90% | 수행 | 수행 |

대체 운동은 근육 기여도 코사인 유사도에서 통증 관절 부하를 뺀 점수로 고릅니다.
애매한 후보를 내놓느니 "대체 없음"을 반환합니다.

```
어깨 4점 → 바벨 오버헤드프레스 ✕ → 머신 숄더프레스 / 랜드마인 프레스
허리 4점 → 컨벤셔널 데드리프트 ✕ → 힙 쓰러스트 / 백 익스텐션 / 워킹 런지
```

대체 종목은 이력이 없어 중량을 정하지 않습니다. 다른 종목의 중량을 임의로 환산하는 것이 더 위험하므로, 원래 종목의 마지막 기록만 참고로 붙입니다.
