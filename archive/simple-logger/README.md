# 건강 기록 (health_project)

체중 · 운동 · 식단 · 수면 · 물 섭취를 기록하고 추이를 확인하는 웹 앱입니다.
빌드 도구나 서버 없이 `index.html`을 브라우저에서 열면 바로 동작합니다.

## 실행

```bash
# 방법 1: 파일 직접 열기
open index.html          # macOS
xdg-open index.html      # Linux

# 방법 2: 로컬 서버 (권장)
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 기능

- **기록 입력** — 날짜별로 체중(kg), 운동(분), 섭취 칼로리(kcal), 수면(시간), 물(잔), 메모를 저장합니다. 같은 날짜로 다시 저장하면 덮어씁니다.
- **요약 카드** — 최근 체중, 목표 체중까지 남은 값, BMI, 최근 7일 운동 합계 / 평균 수면 / 평균 칼로리.
- **차트** — 최근 30일 체중 추이(선 그래프, 목표선 표시)와 최근 14일 운동 시간(막대 그래프). 외부 라이브러리 없이 SVG로 그립니다.
- **기록 목록** — 최신순 표에서 각 기록을 수정하거나 삭제합니다.
- **설정** — 키(cm)와 목표 체중(kg)을 입력하면 BMI와 목표선이 계산됩니다.
- **내보내기 / 가져오기** — 전체 데이터를 JSON 파일로 저장하고 다시 불러옵니다. 가져오기는 같은 날짜를 덮어쓰는 방식으로 병합합니다.

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송되지 않습니다.

| 키 | 내용 |
| --- | --- |
| `health_project.entries.v1` | 날짜별 기록 배열 |
| `health_project.settings.v1` | 키, 목표 체중 |

브라우저 데이터를 지우면 기록도 함께 사라지므로, 중요한 데이터는 **내보내기**로 백업해 두세요.

## 파일 구조

```
index.html        화면 마크업
src/styles.css    스타일 (라이트/다크 모드 지원)
src/app.js        상태 관리, 차트 렌더링, 저장/불러오기
```

## 데이터 형식

```json
{
  "version": 1,
  "exportedAt": "2026-09-17T00:00:00.000Z",
  "settings": { "heightCm": 172, "targetWeight": 65 },
  "entries": [
    {
      "date": "2026-09-17",
      "weight": 68.5,
      "exercise": 30,
      "calories": 2000,
      "sleep": 7,
      "water": 8,
      "memo": "저녁 산책"
    }
  ]
}
```

값이 없는 항목은 `null`로 저장됩니다.

## 참고

BMI 및 요약 수치는 참고용이며 의학적 진단이나 처방을 대신하지 않습니다.
